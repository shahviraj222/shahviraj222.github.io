# Viraj Shah — Personal Portfolio

A responsive, accessible portfolio featuring software engineering, LLM systems, and cloud infrastructure work.

## Files

- `index.html`: portfolio content and search metadata
- `styles.css`: responsive layout and visual design
- `script.js`: mobile navigation, active sections, and copy-email interaction
- `assets/`: resume, favicon, and social preview

## Local preview

Run `python3 -m http.server 4173` in this directory, then open `http://localhost:4173`.

## Hosting

Hosted on GitHub Pages from the `main` branch, repository root. No build step, paid services, API keys, or external JavaScript dependencies are required.

## Editing

Edit the relevant HTML section and push to `main`. To update the resume, replace `assets/Viraj-Shah-Resume.pdf`. If the hosting URL changes, update the canonical URL, Open Graph URLs, JSON-LD, sitemap, and robots file.

All employment and project descriptions are based on the resume supplied by Viraj Shah. The diagrams are conceptual illustrations, not screenshots of employer systems. No analytics or tracking scripts are included.
